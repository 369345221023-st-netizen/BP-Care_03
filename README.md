### สมาชิกคนที่ 3 — ผู้จัดทำเอกสารและประเมินการใช้งาน (Documentation & UX)
รับผิดชอบการจัดทำเอกสารประกอบโครงงาน ตรวจสอบความสะดวกในการใช้งานเว็บไซต์ ประเมินความชัดเจนของเมนูและปุ่มต่าง ๆ รวบรวมภาพหน้าจอและข้อเสนอแนะ รวมถึงช่วยตรวจสอบความครบถ้วนของเอกสารก่อนส่งงาน
